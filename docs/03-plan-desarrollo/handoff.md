## Estado del proyecto

SyncVet es la API de gestión de una clínica veterinaria (Paraguay), con el frontend en el mismo repositorio (`frontend/`, monorepo, R-057). El plan del MVP tiene 11
fases ([`03-plan-desarrollo/README.md`](README.md)); la FASE 0 está completada (R-014) y la FASE 1 también (R-028), con las entregas
1.1 (R-017), 1.2 (R-018 y R-019), 1.3 (R-020 a R-022), 1.4 (R-023 a R-025) y 1.5 (R-026 a R-028) cerradas. La FASE 2, datos

(R-030 y R-031), 2.2a, usuarios (R-032 y R-033), 2.2b, usuarios inactivos, baja, sucursal actual y contraseña propia (R-034 y

([cierre de la FASE 2](fases/backend/fase-02-datos-maestros.md#cierre-de-la-fase-2)). La FASE 3, agenda y turnos, también está

## Decisiones técnicas que hay que tener presentes

| Tema | Decisión |
|---|---|
| Arquitectura | Controller → Form Request → Service → Model → Resource → ApiResponse (`backend/CLAUDE.md` §4) |
| Estados | `string(20)` en la base y Enum en PHP; nunca columnas `ENUM` de MySQL |
| Dinero | `decimal(14,2)` con BCMath; importes en PYG redondeados a 0 decimales (R-004) |
