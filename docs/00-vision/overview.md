# Qué es SyncVet

Sistema de gestión para clínicas veterinarias de Paraguay: agenda, historia clínica, vacunas y recordatorios, documentos,
inventario, caja y facturación electrónica SIFEN, con varias sucursales.

| Dato | Valor |
|---|---|
| Usuarios | Recepción, veterinarios y administración de la clínica |
| Mercado | Paraguay (guaraníes, IVA 5 % y 10 %, SIFEN de la DNIT) |
| Este repositorio | Monorepo (R-057): la API REST (`backend/`) y la aplicación web (`frontend/`) |
| Frontend | React 19 + TypeScript + Vite + Tabler, en `frontend/` del mismo repositorio |

El alcance de cada fase está en [`docs/03-plan-desarrollo/README.md`](../03-plan-desarrollo/README.md).
